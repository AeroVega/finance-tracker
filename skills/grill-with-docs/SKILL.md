Use only when the user explicitly requests `grill-with-docs` or an interview with documentation. Load [grilling](../grilling/SKILL.md) for the interview and [domain-modeling](../domain-modeling/SKILL.md) for recording agreed terms and decisions.

Keep settled decisions, use the existing project documents, and respect the requested question limit or stopping point. Summarize proposed document edits and unresolved issues. Capture only agreed, public-safe decisions within the requested documentation scope; proposed decisions are not implementation or production approval.
