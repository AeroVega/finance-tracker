7. Test crash / reload recovery

  1. Start the lifecycle and confirm it reaches Ready.
  2. For a controlled simulation, press Simulate crash. This stops the heartbeat and discards the in-memory session without writing a release marker.
  3. Wait at least 2 minutes 10 seconds for the two-minute lease to expire.
  4. Press Start / recover application storage. It should refuse automatic takeover and report Stale session.
  5. Use the explicit stale-session recovery button. Recovery should acquire a new session ID, run transaction recovery, and return to Ready.

The controlled simulation is the reliable way to test the stale lease in this harness. A normal pagehide release may run when closing or reloading a tab; in that case the marker becomes Released and the next page can acquire normally, which is safe but does not exercise stale recovery.
