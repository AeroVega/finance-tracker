Finance Tracker · Experiment B

Drive folder discovery

Discovery-only test.

This experiment checks whether a folder explicitly selected once in Google Picker can be rediscovered through Drive's files list after a reload and fresh authorization.

It does not read or change ledger contents and does not create, update, or delete files. The selected folder ID is held in this tab's session storage only so the test can compare results after reload; it is not sent to a server or written to logs.

Connect your Google account

Google handles authorization. This experiment requests only Google's narrow drive.file scope.

1. Select the existing folder once

For the first pass only, use Picker to select the intended private folder. Its ID is retained in this tab's session storage to compare against the discovery result after reload.

2. Discover without Picker

To test discovery on its own, tap “Forget saved comparison” above, then authorize and run discovery. The app searches by exact name. Zero or multiple matches require explicit Picker selection; one match remains only a candidate until identity is verified. The app never creates a replacement folder automatically.

No access tokens, API keys, folder IDs, or file listings are displayed. A successful result tests only this account, browser, folder, and OAuth configuration.
