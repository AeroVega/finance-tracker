Finance Tracker · Prototype only

Google Drive connection check

Synthetic-data check only.

This page creates one temporary invented JSON file in the folder you select, reads it back, and asks before deleting it. It does not read or update your ledger and it never uploads a CSV.

The access token and configuration values stay in this browser tab. The token is not saved between sessions. Keep the Drive folder restricted to your account.

Google Cloud setup

Enable the Drive API and Google Picker API. Use a web OAuth client for the app's HTTPS origin, and restrict the API key to that origin and the Picker API. This page never asks for a client secret.

Select the private folder

Choose the existing Finance Tracker folder from Drive. The folder URL alone does not grant API access; Google will ask you to authorize this app.

The selected folder ID is held only in page memory and is not included in the public source. This prototype uses Google's narrow drive.file permission.
