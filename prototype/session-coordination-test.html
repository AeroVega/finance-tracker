Two-device test sequence

  1. On device A, connect, select the same dedicated synthetic folder, inspect, and acquire.
  2. On device B, connect and select that same folder. Inspect should report A's active session; acquire must be refused.
  3. On device A, release and wait for the verified success result.
  4. On device B, inspect again and acquire. B should now own the session.
  5. To simulate a browser crash, close a page without releasing. Wait at least two minutes, inspect on the other device, then use explicit stale recovery.

This is best-effort coordination, not a server-enforced lock. Simultaneous starts and network partitions can still race. Keep the single-active-device operating rule.
